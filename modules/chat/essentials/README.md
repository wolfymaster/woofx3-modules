# Chat Essentials

All the classic chat commands your viewers already know, ready the moment you
install. Your chat gets fun little games, a way to say hi and bye, and a home
for all the funny things you say on stream. No setup needed!

## What your chat can do

- **!uptime** tells everyone how long you've been live.
- **!lurk** lets a viewer say they're watching quietly. **!unlurk** welcomes
  them back.
- **!8ball** answers any yes-or-no question with a magic 8-ball reply.
  Try: `!8ball Will we win this round?`
- **!roll** rolls dice. `!roll` rolls one normal die, `!roll 20` rolls a
  20-sided die, and `!roll 2d6` rolls two dice and adds them up.
- **!coinflip** flips a coin: heads or tails.
- **!quote** shares a random saved quote. `!quote 5` shares quote number 5.

## Quotes from your stream

Said something hilarious? Save it forever!

- Mods and you can type **!addquote** and then the quote, like
  `!addquote I meant to do that`. It gets a number right away.
- Mods and you can remove one with **!delquote** and its number, like
  `!delquote 5`.

Only mods and the broadcaster can add or remove quotes, so your quote book
stays clean. Quote numbers never change, so "quote 12" is always the same
quote.

## Make it yours

In the module settings you can:

- Write your own **lurk** and **welcome back** messages. Put `{user}` where the
  viewer's name should go.
- Write your own **8-ball answers**. Put a `|` between each one, like
  `Yes!|No way|Ask chat`.

Leave any of these blank to use the built-in messages.

## Ideas to try

- Use the dice roll to let chat decide your next loadout.
- Save your best "fails" as quotes and share them during slow moments.
- Pair !lurk with a thank-you sound so lurkers feel welcome.

## Good to know

- **!uptime** starts counting the next time you go live after installing. If
  you install in the middle of a stream, it will know your start time next
  stream.
- If another module already uses one of these commands, like its own !lurk,
  keep just one so chat doesn't get two answers.
