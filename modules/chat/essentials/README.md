# Chat Essentials

The classic chat commands your viewers already know, ready as soon as you install. No setup needed.

## What you can do

- Tell chat how long you've been live
- Let viewers say they're lurking, and welcome them back
- Answer questions with a magic 8-ball
- Roll dice and flip coins
- Save your funniest moments as numbered quotes

## Chat commands

| Command | What it does |
|---|---|
| !uptime | Says how long you've been live |
| !lurk / !unlurk | A viewer says they're lurking, or that they're back |
| !8ball | Answers a question, like `!8ball Will we win?` |
| !roll | Rolls dice: `!roll` for one die, `!roll 20` for a 20-sided die, `!roll 2d6` for two dice |
| !coinflip | Heads or tails |
| !quote | Shares a random quote, or a numbered one like `!quote 5` |
| !addquote | Saves a new quote (mods and you only) |
| !delquote | Deletes a quote by number, like `!delquote 5` (mods and you only) |

Quote numbers never change, so quote 12 is always the same quote.

## Make it yours

In the module settings you can write your own lurk and welcome back messages (use `{user}` for the viewer's name) and your own 8-ball answers. Leave them blank to use the defaults.

## Good to know

- !uptime starts counting the next time you go live after installing.
- If another module already has one of these commands, keep just one so chat doesn't get two answers.
