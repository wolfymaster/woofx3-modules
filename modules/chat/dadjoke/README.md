# Dad Jokes

Chat can type **!dadjoke** and get a random dad joke. It's an easy way to fill a slow moment and make everyone groan at once.

## What you can do

- Let anyone in chat ask for a dad joke
- Pick from 500 family-friendly jokes
- Skip jokes told recently, so chat doesn't hear repeats

## Chat commands

| Command | What it does |
|---|---|
| !dadjoke | Tells a random dad joke |

If another module already has a !dadjoke command, keep just one so chat doesn't get two answers.
