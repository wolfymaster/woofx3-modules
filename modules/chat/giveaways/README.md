# Giveaways

Run a giveaway right in chat. Viewers type one word to enter, and you or your mods pick a random winner.

## What you can do

- Start a giveaway from chat
- Let viewers enter with one word, once each
- Pick a random winner, and draw again for someone new
- Give subscribers extra chances to win
- Show an alert when a giveaway starts, when someone enters or when a winner is picked

## Setting up

1. Open the Giveaways settings.
2. Choose your entry word. `!join` works great.
3. Set **Subscriber luck**: 1 gives everyone the same chance, 2 gives subscribers twice the chance.
4. Type `!giveaway start` in chat.

## Chat commands

You and your mods can use these. Viewers only need the entry word.

| Command | What it does |
|---|---|
| !giveaway start | Opens the giveaway. Add your own entry word, like `!giveaway start !pizza` |
| !giveaway end | Stops new entries but keeps everyone who joined |
| !giveaway draw | Stops new entries and picks a winner |
| !giveaway cancel | Throws the giveaway away |
| !giveaway | Tells chat how it's going |

Only one giveaway runs at a time. Turn on **Say when someone enters** to thank each viewer in chat, but leave it off in a busy chat.
